# Website Rescue Dubai

The one-page website for my website repair service in Dubai. It is for business owners whose site is down, slow, shows a "Not secure" warning, or is hard to use on a phone. The page explains what I fix, gives one clear price for each job, and shows how to get in touch.

Live site: https://p32929.github.io/website-rescue-dubai/

## What is in this repo

1. `index.html`: the whole page. Plain HTML and CSS in one file, with no build step and no outside scripts.

## Run it

Open `index.html` in any browser. To publish it, push to the default branch: GitHub Pages serves it as is.
